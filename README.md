# 永裕光电 · 展会英语陪练（网页版）

手机浏览器直接打开下面这个链接即可使用，建议用 Safari 打开后「分享 → 添加到主屏幕」，
之后就是一个全屏、可离线的 App 图标（首次在线打开过一次即可离线使用）。

链接：`https://<你的用户名>.github.io/<仓库名>/`

## 内容

- 150 条中英对照专业术语（规格参数 / 产品系列 / 工艺品质 / 商务认证 / 公司介绍）
- 35 个系列、188 个型号的产品参数，含 113 页原始画册页对照
- 106 组客户提问与「口语简版 + 专业详版」英文标准答案
- 16 篇讲解稿（公司介绍 30/60 秒、产品线与主推型号、现场话术）
- 28 天逐日冲刺计划 + 跟读训练（逐词对照与匹配度）

## 说明

- 除语音识别外全部离线可用；语音朗读使用系统 TTS，不需要联网。
- 想更新内容：重新运行 `build.py` 生成 `publish/index.html`，然后 `git commit && git push`。
- 站点由 GitHub Pages 从本仓库根目录的 `main` 分支发布。
